# Dunkelmodus Toggles

Willkommen bei **Dunkelmodus Toggles**! Dieses Projekt ermöglicht es Entwicklern, ihren Benutzern die Möglichkeit zu geben, zwischen dem klassischen Modus und dem Dunkelmodus zu wechseln.

## Funktionen
- **Einfache Integration**: Fügen Sie einfach einen JavaScript-schnipsel und ein paar CSS-Regeln hinzu, um Dunkelmodus-Unterstützung zu aktivieren.
- **Benutzeranpassung**: Benutzer können ihre bevorzugte Farben, Schriftarten und Layouts speichern.
- **Persistenz**: Speichern Sie die Benutzereinstellungen lokal, damit die Auswahl bei zukünftigen Besuchen erhalten bleibt.
- **Flexible Anpassungen**: Unterstützung für verschiedene Themen und Farbpaletten, die jederzeit geändert werden können.

## Installation
```bash
npm install dunkelmodus-toggles
```

## Nutzung
1. Importieren Sie die Bibliothek in Ihr Projekt.
2. Fügen Sie den Dunkelmodus-Toggle-Button in Ihrer Benutzeroberfläche hinzu.
3. Definieren Sie die Farbschemata in CSS.

## Beispiel
```html
<button id="toggle-button">Toggle Dunkelmodus</button>
<script src="dunkelmodus-toggles.js"></script>
```
